# Prediction sensitivity analyses

These scripts are alternative or experimental analyses and are not required to reproduce the primary prediction models in the parent directory.

| Filename marker | Analysis variation |
|---|---|
| `fem` / `male` | Sex-stratified model |
| `finngen` / `rep` | External or replication cohort |
| `raw` | Unadjusted biomarker input |
| `tech` | Technical-covariate adjustment |
| `14` / `14pan` | Expanded 14-panel Olink dataset |
| `nocv` | Model fitted without cross-validation |
| `chrono` | Chronotype-related outcome |
| `_2` | Revised implementation retained for comparison; equivalence to the primary workflow has not yet been established |

When a sensitivity analysis is selected for publication, rename it using a descriptive name and record its input cohort, feature set, model, and relationship to the primary analysis in the main README.
